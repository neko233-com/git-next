# git-next native compatibility core

This directory contains git-next's source overlay, declared upstream patches and pinned sources for its primary native compatibility core. The upstream Git core and the files in `overlay/` are **GPL-2.0-only**; see `LICENSE.GPL-2.0`. `vendor/yyjson/` retains its MIT license and source provenance. The Rust preview's existing license is unchanged; it is not linked into the C core.

Use `tools/prepare_native_core.py` for the pinned upstream source and `tools/integrate_native_core.py` to apply the exact declared patches and overlay. Integration records original, patch, overlay and generated catalog hashes. The Chinese catalog is generated from the pinned upstream `po/zh_CN.po`, retaining its contributor attribution; user strings and machine output are not translated.

`tools/build_native_core.py` compiles production targets and writes an immutable receipt without running them. Windows runtime assets are prepared separately with `tools/fetch_windows_runtime.py`, `tools/prepare_windows_runtime.py` and `tools/prepare_windows_iconv.py`; upstream core executables are excluded. `tools/prepare_windows_psl.py` supplies pinned public-suffix imports. `tools/assemble_native_windows.py` assembles the complete owned x64 distribution; `packaging/build_msi.py --distribution` compiles the full MSI payload without executing the core. Other platforms and final acceptance remain open. The optional real OpenSSL provider is independently obtained through its pinned component catalog and is excluded from the public payload. See the [native integration report](../docs/NATIVE_CORE.md) for primary-helper, encoding, provenance and remaining package boundaries.

These are implementation inputs for the [fixed delivery scope](../docs/DELIVERY_STATUS.md). A compiled core is not a complete distribution, accepted runtime or permission to activate an incomplete default `git`. No installed Git/OpenSSH is a runtime fallback. All product regression and performance runs wait until D01–D07 are complete.

The MIT `launcher/` sources build CRT-free Windows legacy bridges through `tools/build_windows_bridge.py`; their source/resource/license boundary is separate from the GPL core overlay. The native system-config patch selects the additive migrated system file while preserving explicit Git config overrides. See the takeover guide for ownership, backup and recovery scope.
